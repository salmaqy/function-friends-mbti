Function Friends — MBTI teaching course

Open index.html in a browser. No build step or server is required.

Available lessons:
- Lesson 1: Understanding Personality and the Origins of MBTI
- Lesson 2: The Four MBTI Preferences (unlocks after Lesson 1)

Each lesson contains teaching material, knowledge checks, practical examples,
teach-back prompts, and a suggested answer guide. Progress and written answers
save in that browser using local storage. Clear local storage for this page to
reset saved answers.

Files:
- index.html: page structure
- style.css: visual design and responsive layout
- script.js: lesson content, checks, and saved progress

The page uses Google Fonts when online and falls back to local fonts otherwise.
